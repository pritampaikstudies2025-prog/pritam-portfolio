PRITAM PAIK — PORTFOLIO WEBSITE
================================

FILES
- index.html : page content and comments showing where each certificate image belongs
- style.css  : design, responsive layout, hover effects and transitions
- script.js  : mobile menu, scroll animations and certificate image loading
- images/    : put all certificate JPG images here

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It opens in your browser.
4. For online publishing, upload the whole folder, including the images folder.

CERTIFICATE IMAGE FILENAMES
Put all images in the single images/ folder using these exact filenames:
1. images/business-analytics-with-excel.jpg   (1240 x 1755)
2. images/machine-learning-with-python.jpg    (1240 x 1755)
3. images/encoder-decoder-networking.jpg       (1240 x 1755)
4. images/capm-ms-office.jpg                   (1240 x 1755)
5. images/inventory-valuation-tally-gst.jpg   (1240 x 1754)
6. images/higher-secondary.jpg                (850 x 1169)
7. images/secondary.jpg                       (826 x 1145)

The website only reads the image files from the images/ folder. Keep the exact filenames above, then refresh index.html. Each image will appear in its matching certificate slot automatically.
It does not search other folders on your computer. No need to edit HTML if you keep the filenames and folder unchanged.

CUSTOMISATION
- Your name, About Me text, skill descriptions, education, certificate titles and contact email are in index.html.
- The HTML comments immediately above every certificate card explain which file goes in which slot.
- Skill progress bar percentages are visual placeholders; adjust the --level percentages in index.html to reflect your actual proficiency.
- The contact email is the one provided in the request.

NOTE
Certificate filenames should end in .jpg (lowercase). If an image is actually .jpeg or .JPG, rename it to match the filenames above, or update the corresponding src in index.html.
